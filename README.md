# Just Dion Portfolio

An interactive portfolio for Dion, built with React and Vite.

## Run locally

```powershell
cd frontend
npm install
npm run dev
```

Create and preview a production build:

```powershell
npm run build
npm run preview
```

## Deploy on Vercel

Import the repository into Vercel and set the project **Root Directory** to
`frontend`. Vercel can detect Vite automatically; use `npm run build` as the
build command and `dist` as the output directory. No environment variables are
required.
